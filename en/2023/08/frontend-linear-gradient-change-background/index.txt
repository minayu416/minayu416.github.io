c:Tca0,<p>Since I'm developing my own product and using a lot of gradient color as background color, as a new Front-end learner, this issue stuck me a while, so I would like to share the solution I found.</p>
<h2 id="requirement-introduce">Requirement Introduce</h2>
<p>As the picture shows.</p>
<p><img src="https://minayu0416.files.wordpress.com/2023/08/screenshot-2023-08-12-at-9.33.08-pm.png" alt=""></p>
<p>This is one of the page in my product, I used the linear-gradient effect in the square.</p>
<p>Here is my CSS and html code:</p>
<pre><code class="language-html">&#x3C;div className="h-32 w-32 rounded-[20px]">
  &#x3C;div className="h-32 w-32 rounded-[20px] border square">&#x3C;/div>
&#x3C;/div>
</code></pre>
<pre><code class="language-css">.square {
  border-color: #eacb84;
  background: linear-gradient(
    to bottom right,
    rgba(255, 255, 255, 0.4),
    rgba(255, 255, 255, 0.2)
  );
}
</code></pre>
<p>In this product, user needs to choose square, so I want to add a new effect to show if user choose the square, as picture shows.</p>
<p><img src="https://minayu0416.files.wordpress.com/2023/08/screenshot-2023-08-12-at-9.33.16-pm.png" alt=""></p>
<p>In the begining, I though this is very easy, only use hover and change background color can achieve the requirement. However, I was wrong, it didnt work.</p>
<h2 id="solution">Solution</h2>
<p>Since I'm a self-learner of Front-end, I only found this solution, if anyone has better solutions, please share to me, I will update the article.</p>
<p>This is the reason why change backgound color doesn't work:</p>
<p><strong>The priority of using linear-gradient as background color is higher then other simple backgound color, so change background color doesn't work.</strong></p>
<p>The solution I found is using <code>overlay</code> + <code>absolute</code> to resolve the bug. Add a new div in front of the original square div and using absolute to <strong>cover</strong> the background-color of the square div.</p>
<p>Here is the code:</p>
<pre><code class="language-html">&#x3C;!-- Remember to add relative, because we want the overlay div absolute and cover the square div  -->
&#x3C;div className="relative h-32 w-32 rounded-[20px]">
  &#x3C;!-- Because I use React.js, so when user choose specific div, this will add the div overlay. -->
  &#x3C;!-- You can change the JS or handle event style according the framework you use. -->
  {selectedDiv === square.id &#x26;&#x26;
  &#x3C;div className="overlay">&#x3C;/div>
  }
  &#x3C;div className="h-32 w-32 rounded-[20px] border square">&#x3C;/div>
&#x3C;/div>
</code></pre>
<pre><code class="language-css">.overlay {
  /* position is absolute, cover the background of square div */
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  border-radius: 20px;
  background-color: rgba(234, 203, 132);
  opacity: 0.4;
}
</code></pre>
<p>And that's done:</p>
