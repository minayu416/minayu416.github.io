c:T1bf6,<p>趁記憶還猶新，趕緊來記錄起來</p>
<p>我才剛用 hugo 又產生了一個新的網站，並成功架在我的 Github</p>
<p>之前我一直以為 Github 只能架一個網站，直到我同事跟我談話中提點，我才知道原來可以架很多個網站。</p>
<p>但這樣講其實也不太正確啦 ~</p>
<p>接著進入我們的主題吧</p>
<h1 id="如何架設多個網站">如何架設多個網站？</h1>
<p>根據 <a href="https://gohugo.io/hosting-and-deployment/hosting-on-github/#types-of-github-pages">Host on Github</a> 的 Hugo 文件</p>
<p>提供了兩個做法:</p>
<pre><code>1. User/Organization Pages (https://&#x3C;USERNAME|ORGANIZATION>.github.io/)

2. Project Pages (https://&#x3C;USERNAME|ORGANIZATION>.github.io/&#x3C;PROJECT>/)

</code></pre>
<p>你現在看到我這個網站原先是 <code>https://&#x3C;USERNAME|ORGANIZATION>.github.io/</code> 這個方法，只是我有買網域。</p>
<p>但先前因為上述提及我的功力太弱，所以看不懂也沒有使用過第二個方案，也就完完全全的以為 Github 只能架一個網站</p>
<p>由於這個福音 XD，我也就可以實現我之前夢寐以求想要架一個圖廊來放我拍的照片加上紀錄生活</p>
<p>那由於我認為先前的<a href="/2019/01/from-wordpress-to-hugo/">[BLOG] 從 WORDPRESS 移動到 HUGO</a> ，沒有很清楚明白地說明怎麼架設在 Github 上，所以我也就在介紹一次</p>
<h3 id="第一個方法-httpsusernameorganizationgithubio">第一個方法: https://&#x3C;USERNAME|ORGANIZATION>.github.io/</h3>
<p>備妥好你做的 hugo 網站後</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.23.50.png" alt=""></p>
<p>我們先產生出最後要部署到 Github 上的資源</p>
<p>＊請注意 config 的 baseurl 為 <code>https://&#x3C;USERNAME>.github.io/</code> username 是你在 github 的 username</p>
<p>請打開 Terminal 並在你的 hugo 網站資料夾跟目錄 run</p>
<blockquote>
<p>hugo</p>
</blockquote>
<p>接著會產生出 <code>public</code> 的資料夾，這個是我們待會要部署上去的一大包 html 資源</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.25.55.png" alt=""></p>
<p>若是這種方法，我們是將網站架在你的 github 的主頁</p>
<p>就是 <code>https://&#x3C;USERNAME>.github.io/</code> 代表的會是你的網站主網址 (也只有這個是主要網址，其他的就要加/repositories name)</p>
<p>在你的 Github 上開一個新的 Repositiries，取名 <code>&#x3C;USERNAME>.github.io</code>, <code>&#x3C;USERNAME></code> 是你在 Github 網址上出現的 username</p>
<p>假設我的是 <code>https://github.com/minayu416</code>, 那我就要開 <code>minayu416.github.io</code></p>
<p>接著回來 Terminal, 切進剛剛產生的 <code>public</code> 資料夾</p>
<blockquote>
<p>cd public</p>
</blockquote>
<p>先 commit 剛剛產生的內容</p>
<blockquote>
<p>git add .</p>
</blockquote>
<blockquote>
<p>git commit -m "push public"</p>
</blockquote>
<p>將產生的內容 remote 到剛剛產生的 repositories</p>
<blockquote>
<p>git remote add origin <a href="https://github.com/">https://github.com/</a>/.github.io.git</p>
</blockquote>
<blockquote>
<p>git push -u origin master</p>
</blockquote>
<p>那段 remote 太長的話，你可以按照剛剛剛開的 repositories 指令貼上執行</p>
<p>接著到剛剛創的 repositories > Settings 將 Github Page 打開</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.41.35.png" alt=""></p>
<p>選擇 <code>master branch</code></p>
<p>如果都執行沒問題的話，稍等會就能進 <code>https://&#x3C;USERNAME>.github.io/</code> 看看你剛剛產生的檔案囉！</p>
<h3 id="第二個方法-httpsusernameorganizationgithubio">第二個方法: https://&#x3C;USERNAME|ORGANIZATION>.github.io//</h3>
<p>其實跟上個方法差不多</p>
<p>這個方法會將你的網站放在: <code>https://&#x3C;USERNAME|ORGANIZATION>.github.io/&#x3C;PROJECT>/</code></p>
<p>也是 <code>https://&#x3C;USERNAME|ORGANIZATION>.github.io/&#x3C;REPOSITORIES NAME>/</code></p>
<p>那就開始吧！</p>
<p>一樣備妥好你做的 hugo 網站後</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.23.50.png" alt=""></p>
<p>我們先產生出最後要部署到 Github 上的資源</p>
<p>＊這次請特別注意 config 的 baseurl 為 <code>https://&#x3C;USERNAME>.github.io/&#x3C;REPOSITORIES NAME>/</code> username 是你在 github 的 username</p>
<p>要記得因為這次的網站網址是放在 <code>/&#x3C;PROJECT>/</code> 所以 config 的 baseurl 也要做更改</p>
<p>接著一樣打開 Terminal 並在你的 hugo 網站資料夾跟目錄 run</p>
<blockquote>
<p>hugo</p>
</blockquote>
<p>接著會產生出 <code>public</code> 的資料夾，這個是我們待會要部署上去的一大包 html 資源</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.25.55.png" alt=""></p>
<p>那若是這第二種方法，是將網站用 project 的方式架在 project 名稱的子網域(就是 repositories name!)</p>
<p>此時 <code>https://&#x3C;USERNAME>.github.io/&#x3C;REPOSITORIES NAME>/</code> 代表的會是你這個網站的網址</p>
<p>在你的 Github 上開一個新的 Repositiries，取名就取你想要的名稱，這個名稱將會帶在 <code>https://&#x3C;USERNAME>.github.io/&#x3C;這>/</code>，一樣 USERNAME 是你在 Github 網址上出現的 username</p>
<p>那我就假設我開了一個新的 repositories 叫做 <code>demo</code>，我的 username 是 <code>minayu416</code>， 那網址就會是<code>https://minayu416.github.io/demo/</code></p>
<p>接著回來 Terminal, 切進剛剛產生的 <code>public</code> 資料夾</p>
<blockquote>
<p>cd public</p>
</blockquote>
<p>先 commit 剛剛產生的內容</p>
<blockquote>
<p>git add .</p>
</blockquote>
<blockquote>
<p>git commit -m "push public"</p>
</blockquote>
<p>將產生的內容 remote 到剛剛產生的 repositories</p>
<blockquote>
<p>git remote add origin <a href="https://github.com/minayu416/demo.git">https://github.com/minayu416/demo.git</a></p>
</blockquote>
<p>＊ 記得改成自己的</p>
<blockquote>
<p>git push -u origin master</p>
</blockquote>
<p>那段 remote 太長的話，你可以按照剛剛剛開的 repositories 指令貼上執行</p>
<p>接著到剛剛創的 repositories > Settings 將 Github Page 打開</p>
<p><img src="https://minayu0416.files.wordpress.com/2019/04/e89ea2e5b995e5bfabe785a7-2019-04-23-e4b88be58d886.41.35.png" alt=""></p>
<p>選擇 <code>master branch</code></p>
<p>如果都執行沒問題的話，一樣稍等會就能進 <code>https://&#x3C;USERNAME>.github.io/&#x3C;REPOSITORIES NAME>/</code> 看看你剛剛產生的檔案囉！</p>
<p>依我的為例子的話，網址就是 <code>https://minayu416.github.io/demo/</code></p>
<p>若有問題在麻煩問我喔！</p>
