2017 四國之旅 Day2 松山～道後溫泉

2017.05.26·2 分鐘閱讀

啊...！

手機編輯器又跳掉了～～

只好分第三篇了！

不過也是第二天的最後一部曲

你準備好了嗎 XD

基本上，就是坐著往松山的電車狂浪況郎的到松山～

然後就去旁邊買明天要從松山拉車到高知的地方～

接著感覺附近還好沒什麼特別的，就過地下道去坐往道後溫泉的車了！

接著做路面電車

接下來就往旅館走～

會經過一條商店街還不錯唷～

不過～

越走越偏僻，讓我覺得我是不是又訂到雷飯店了嗚嗚嗚嗚

不要讓我在日本四天都住雷旅館我臉都會綠掉

結果

外面看起來很古色古香～

感覺是一間不錯的古色旅館～

中庭小花園！！超美麗！！

今天的旅館！！超美都哭歪了

也蠻安靜的，除了隔音沒有很好還有走路會震動@@！ 最後就是進剛剛的溫泉街先吃飯！！

這家就在進溫泉街沒多久！！蠻好吃的！

然後在這條街的一家筷子店買了很多禮物，因為這家筷子店可以免費在筷子上刻名字喔！ 對面是買和色的物品店！

就是美麗的花色的商品店，像是錢包～髮展之類的都是用類似和服或者傳統花色等花邊花色的花樣（是在講什麼） 最後附上一張沒有搭到的機票

然後我後來去抽的戀愛的籤

是超大吉耶！！！

好吧，反正我現在也正在打拼目標沒什麼時間物色男生囧！！

夢想達成了再來交男友吧！

那麼就明天啦！ 今天旅館住 Dogoya ryokan
