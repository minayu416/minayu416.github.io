01　ガン！！為什麼不一開始就這麼做？你浪費老娘好多時間！！！

在一個很混亂很混亂的情況下

學長建議我做個筆記

廢話我當然混亂

經過昨天那群鳥事後

我今天還得被學長催催催怪怪怪

然後被學弟各種百般靠腰跟靠北

於是在我恩威並施後，學弟終於受不了我這智障，肯幫我把東西掛載上去了。

ガン！！為什麼不一開始就這麼做？你浪費老娘好多時間！！！

先打一下我今天的經過

我昨天進了主要 VMware 的 ip，然後按照步驟去載了 VMware 的 sphere vClient 端。

然後無法載 server 端，搞了老半天才發現

不用 server 端，用 Client 端就能連

ip 然後

連學弟給的 root

密碼是學弟給的一堆亂碼後

進到了 VMware

找到某台機器，然後在右邊 storage 那邊對 TB 按右鍵，把 ova 載上去。

至於怎麼掛載的就別問了，因為不是我掛載的

簡單來說 ova 就是要 import 然後算是開一個新的環境。

學弟給了我 ip 跟終端機可以登的帳號密碼。

我一直以為這個就是拿來登 wordpress 後台的

記得用火狐開，才不會有 coockie 的問題跳出來

但我錯了，如果要知道這個的帳號跟密碼，請去找 bitnami 公司的說明書來看

然後登進去後，就把密碼改掉吧！！

然後據說要有 domain 才能開通一些功能！！！

那這次先這樣囉～

On this note
