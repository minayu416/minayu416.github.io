<p>週六</p>
<p>午後，是個令人舒適想睡的環境</p>
<p>不過還是被我的程式腦給喚醒</p>
<p>接觸 Django 應該差不多一年了</p>
<p>就是去年的現在</p>
<p>指導老師要我把我寫的 php 全部轉成 Django</p>
<p>真是個噩夢</p>
<p>但我還是轉過來了</p>
<p>習慣了 Django 的模式後，我發現我比較喜歡這樣 MVT(MVC)的模式了</p>
<p>想起今年四月時候接觸 wordpress</p>
<p>然後那時候稍微架了一下也是用 Python 寫的 CMS "Plone"</p>
<p>接著就被學長壓著學 Wordpress</p>
<p>老實說沒有很喜歡被人家壓著學什麼</p>
<p>我比較喜歡在無壓力的環境下自己鑽研</p>
<p>有鑒於自己當初學的時候，被學弟臭唸一頓</p>
<p>不服輸的自己就來自己研究，然後發現了 Django 內建的後台</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-19-at-12-59-25-pm.png" alt="Screen Shot 2017-08-19 at 12.59.25 PM"></p>

<p>後來知道需要 migrate/makemigrations</p>
<p>我就慢慢再回來研究這塊</p>
<p>但這樣簡簡單單的後台，背後是自己一個一個塞小 Tag 進去</p>
<p>也就是說要自己去設計該塞哪邊，該怎麼去轉換資料進 html</p>
<p>因為畢竟我是先抄人家的網站 Html 再去想辦法做他的後台</p>
<p>跟現在的 CMS，先做後面在設計前面是相反了</p>
<p>為了讓現在我正在幫學校設計的網站好用一點</p>
<p>目前趁沒辦指導老師抓走之餘，來鑽研這塊</p>
<p>本來這樣的時間應該是拿來唸英文的</p>
<p>但最近突然找回自己的道路後，就慢慢回來研究 Python</p>
<p>不過發這篇文大概要讓人家失望了</p>
<p>因為我只會貼幾個網站</p>

<p>不過，我還是很感謝他讓我從前端包後端再包資料庫</p>
