b:T15b3,<p>主題蠻抽象的，不過正是剛剛在開發網頁時新學到的</p>
<p>開發網頁的部分，我認為 php 還算是好上手的語法</p>
<p>因為當我的教授在操我網頁這塊時</p>
<p>也是先讓我摸了一陣子 php</p>
<p>直到 deadline 前，才突然叫我改成 django</p>
<p>接著，為了學 django，我就花了很多很多的時間</p>
<p>因為我覺得其實還算挺複雜的</p>
<p>再加上很怕把伺服器寫壞</p>
<p>首先</p>
<p>開好了一個資料夾(website)，在裡面灌好 pip, django, python....等之後</p>
<p>用 manage.py 指令 startproject(project)</p>
<blockquote>
<p>manage.py</p>
</blockquote>
<blockquote>
<p>project</p>
</blockquote>
<blockquote>
<p>settings.py</p>
</blockquote>
<blockquote>
<p>urls.py</p>
</blockquote>
<blockquote>
<p>wsgi.py</p>
</blockquote>
<blockquote>
<p><strong>init</strong>.py</p>
</blockquote>
<p>應該會長這個樣子</p>
<p>project 裡面會有設定檔, url 跟另外兩個還不知道做什麼的檔案</p>
<p>接下來就要開啟一個一個 app</p>
<p>使用 python manage.py 指令 startapp</p>
<p>先開啟一個 main 的 app</p>
<p>之後整個資料夾的樹會長這樣</p>
<blockquote>
<p>manage.py</p>
</blockquote>
<blockquote>
<p>project</p>
</blockquote>
<blockquote>
<p>settings.py</p>
</blockquote>
<blockquote>
<p>urls.py</p>
</blockquote>
<blockquote>
<p>wsgi.py</p>
</blockquote>
<blockquote>
<p><strong>init</strong>.py</p>
</blockquote>
<blockquote>
<p>main</p>
</blockquote>
<blockquote>
<p>view.py</p>
</blockquote>
<blockquote>
<p>model.py</p>
</blockquote>
<blockquote>
<p>(應該還有其他的)</p>
</blockquote>
<blockquote>
<p>template</p>
</blockquote>
<p>至於專門放 html 的 template</p>
<p>會跟 main 還有 project 同一層</p>
<p>url.py 跟 settings.py 只會有各一個</p>
<p>但是不同的 app 有不同的 view 和 model</p>
<p>每開一個 app 就需去 settings.py 裡寫上新開的 app</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-17-at-10-31-52-am.png" alt="Screen Shot 2017-08-17 at 10.31.52 AM"></p>
<p>像是這樣</p>
<p>而 Django 的工作流程，我把他解釋為</p>
<p>url >> view >> model >> template</p>
<p>不過這篇還不會介紹到 model</p>
<p>打開 url.py</p>
<p>通常會在這邊寫出一行一行網頁....</p>
<p>就是 url 網址後面那串(好不專業)</p>
<p>舉一個例子，會看到一行一行像下面這樣的程式碼</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-17-at-10-34-40-am.png" alt="Screen Shot 2017-08-17 at 10.34.40 AM"></p>
<p>假設這個主網域的網址叫做 <a href="http://www.wordpress.com">www.wordpress.com</a></p>
<p>那麼這行指令就是當你在網址上打</p>
<p><a href="http://www.wordpress.com/data_course823/">www.wordpress.com/data_course823/</a></p>
<p>會跳出另外一個頁面</p>
<p>程式碼的意思就是當你輸入</p>
<p><a href="http://www.wordpress.com/data_course823/">www.wordpress.com/data_course823/</a></p>
<p>他會執行後面亮綠色 data_course823 的動作</p>
<p>而這個動作我們會寫在 views.py</p>
<p>打開 views.py</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-17-at-10-35-29-am.png" alt="Screen Shot 2017-08-17 at 10.35.29 AM"></p>
<p>這裡寫的就是一個一個在 url 輸入的動作</p>
<p>def 定義 data_course823</p>
<p>回傳 data_course823.html</p>
<p>這樣的動作，是沒有牽涉到 model</p>
<p>不要忘了 import 指令唷！</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-17-at-10-35-52-am.png" alt="Screen Shot 2017-08-17 at 10.35.52 AM"></p>
<p>其實 url.py</p>
<p>一個 project 只會有一個</p>
<p>所以不管是哪個 app 的動作或者網址</p>
<p>都是寫在同樣一個 url.py</p>
<p>萬一有好幾個不同的 app 的話</p>
<p>就需要在 url.py 裡</p>
<p>利用註解跟空行將寫上去的 url 程式碼做一些整理，看起來才不會亂</p>
<p>無論是寫在哪個 app，url 的寫法都是一樣的</p>
<p>url(r'^admin/', include(admin.site.urls)),
url(r'^$', index),
url(r'^firstweb/', firstweb),
url(r'^second/', second),
url(r'^third/', third),</p>
<p>通常會將網址和後面的動作取一樣的，以免搞混</p>
<p>接著只要在 url.py 上方 import 不同 app 的 views 就可以了</p>
<p><img src="https://minayu0416.files.wordpress.com/2017/08/screen-shot-2017-08-17-at-10-34-08-am.png" alt="Screen Shot 2017-08-17 at 10.34.08 AM"></p>
<p>這樣不管是在哪個 app 寫好 views, 都能正確的回應 url.py 呼叫的動作囉！</p>
<p>url.py
from main.views import _
from test.views import _</p>
<p>url(r'^$', index),
url(r'^firstweb/', firstweb),
url(r'^second/', second),
url(r'^third/', third),</p>
<p>main.views</p>
<p>from django.shortcuts import render_to_response
from main.models import *</p>
<p>def index(request):
return render_to_response('index.html')</p>
<p>def firstweb(request):
return render_to_response('firstweb.html')</p>
<p>test.views</p>
<p>from django.shortcuts import render_to_response
from test.models import *</p>
<p>def second(request):
return render_to_response('second.html')</p>
<p>def third(request):
return render_to_response('third.html')</p>
<p>template 裡要有</p>
<p>index.html</p>
<p>firstweb.html</p>
<p>second.html</p>
<p>third.html</p>
<p>對應的 html 喲！</p>
<p>這樣 views 裡面的動作才能對應 url.py 下的指令</p>
