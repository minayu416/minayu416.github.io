c:T1387,<p>好久沒來這撰寫我的文章了</p>
<p>至從上個月 3 號衝動之下買了三年費的 bluehost，一鍵安裝 wordpress 來試試看</p>
<p>反正有一個月內免費退費機制，但我覺得第一次買三年很划算</p>
<p>當初是因為自己單方面認為初次買三年很便宜＋送一年 Domain</p>
<p>而且三年感覺很久，我可以有一個自己的網站＋自己制訂的 Domain 三年？</p>
<p>然後三年後期限到了再想想辦法，但才剛到一個月半，也就是這兩天的時候突然就有點打住覺得不太對勁</p>
<p>當初想換部落格無非是因為這個部落格的功能不夠了，所以換個地方擴展</p>
<ul>
<li>照片存放空間太少了(Wordpress 免費版僅提供 3GB)，我寫旅記的話會需要傳大量的照片</li>
<li>想要自由地玩主題，我一直都希望可以自己編訂前端的部分</li>
</ul>
<p>所以我認為只要租個主機，架 wordpress.org 就可以滿足我的需求</p>
<p>在去年 12/29 時也嘗試過想將 Wordpress.org 架在亞馬遜的 EC2 服務上，結果由於自己功力不夠，失敗多次才成功，造成繼續的興趣缺缺</p>
<p>曾經我也打量過各種方案與辦法，但根據自己的當時的狀況，最後還是評估持續使用 Wordpress.com 的網站</p>
<p>這次也因為剛畢業，進入工作，沒有以前研究所的沒日沒夜，以及有薪水收入</p>
<p>所以想說工作穩定有時間經營部落格加上工作有薪水，就買了三年的 Bluehost，打算再從 0 開始慢慢成長</p>
<p>等到我真的遷入過去後才發現真的蠻麻煩的，有需多事情是我沒有考量到的</p>
<ul>
<li>安全問題，wordpress 是架站大眾，因此一定會有很多駭客想駭網站，資安的部分真的還得自己搞</li>
<li>我是租 bluehost, 但我用 jetpack, WP statistics 來看流量時，國家的部分會一律被 bluehost 攔截，所以我只看得到統一是美國某個地區來看我的網站</li>
<li>我覺得 bluehost 內部的統計不是很好用就是 xD ( 這方面可以用 Google Analytics 補足)</li>
<li>我裝過 WP statistic, 可是它顯示的人數跟 Jetpack 還有 bluehost 的統計人數都不同，我也不知道我該看哪個統計比較標準</li>
<li>有時候要先登入 bluehost 來進入 wordpress 後台</li>
<li>我發現原來我自己架 wordpress.org 的時候可以安裝很多套件，但也需要安裝很多套件，而讓我的後台感覺肥肥的</li>
<li>bluehost 租三年便宜，但之後續約據說爆貴</li>
<li>我剛遷 domain, SEO 歸零重新做很想哭哭了，若之後不用 bluehost 的話我的 domain 還在嗎？</li>
</ul>
<p>以上幾件事情，綜合一下包括網站</p>
<ul>
<li>安全問題</li>
<li>套件統計人數不一致</li>
<li>主機續約價錢昂貴</li>
<li>換 Domain = 重新耕耘 SEO</li>
</ul>
<hr>
<p>再來進到主題的部分，</p>
<p>我一直希望自己能夠自己玩網頁的前端設計</p>
<p>看很多用 Wordpress 架的網頁是可以自己調主題</p>
<p>但是我換到 Wordpress.org 時，我還是只套 Wordpress 付的樣板，頂多樣版改一改就沒了</p>
<p>真要自由的玩前端設計，在更改的時候，面對眾多 php 檔案，也是敗下陣</p>
<p>尤其用 Bluehost 架設，若想更改 php 是用 bluehost 後台進去介面做更改，對於我們這些時常用編譯器敲敲打打的工程師，好像有這麼一點點麻煩 XD</p>
<p>於是</p>
<h3 id="我還是回到了-wordpressorg">我還是回到了 Wordpress.org</h3>
<hr>
<p>最近在尋找下個架站資源，然後經過這次搬家的教訓，我會再規劃調查的更完整，還有內容要怎麼規劃擴展在進行，等到確定都 Ready 才會考慮搬家</p>
<p>針對自己想架站，總是有許多吹毛求疵的點，以往不論是到 AWS 架站還是這次搬家到 Bluehost，都是憑著自己太陽牡羊座的衝動，兩日完成</p>
<p>好像沒有考量到許多點(雖然已經累積許多想要換網站的動力，才會一次爆發)</p>
<p>也許這次得考量多一點，才能決定要使用什麼架站資源來滿足我心</p>
<p>經過幾天上網爬了文章，加上之前同事跟我提及的 Hugo</p>
<p>我發現可以使用<a href="https://gohugo.io/">Hugo</a>架在<a href="https://github.com/">GitHub</a>上，而且我還找到了<a href="https://forestry.io/">CMS</a>開源軟體去搭配</p>
<p>再加上如果要從 wordpress 搬過去的話可以使用我找到的<a href="https://gohugo.io/tools/migrations/">exporter</a></p>
<p>經過長達兩週的調查(實際上是這兩週公司開發太忙碌)，我慢慢的去了解 Hugo</p>
<p>甚至也在 12/29 日開始動手實作，學習另外一種架站資源</p>
<p>被我發現到了新名詞與比較: SSG 與 CMS。</p>
<p>原來寫個部落格跳脫市面上許多平台，還可以有很多不同的選擇，實在是太有趣啦！</p>
