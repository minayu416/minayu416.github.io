<h3 id="熱身指南">熱身指南</h3>
<ol>
<li>
<p>學習 Debug Tool, 並利用 Debug 工具追蹤程式流程。</p>
</li>
<li>
<p>學習 Design Pattern。 先專注於 Template Method Pattern。能舉實例說明，如何演化一段程式為 Template Method Pattern</p>
</li>
<li>
<p>找一個專案程式為範本，試著還原最起始狀態，運用 Template Method Pattern 來演化出一套 Framework</p>
</li>
</ol>

</li>

</li>
<li>

</li>
